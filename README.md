# Explica Studio Ultra V14

Correções principais:
- quebra automática reescrita com medição real de altura em um elemento invisível independente da prévia;
- funciona da mesma forma no desktop e no mobile;
- fontes externas removidas do funcionamento crítico;
- fonte da interface baseada em fontes do sistema;
- fontes do post usam pilhas seguras e a própria fonte escolhida é usada no cálculo da quebra;
- quebra considera formato, tamanho da fonte e presença/posição da imagem;
- cache busting atualizado para v14.0.0.

Publicação na Vercel: substitua a pasta do projeto pela V14 e faça novo deploy.
